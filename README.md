# Spider

Spider is an experimental compiler based on WebAssembly semantics and the Regionalized Value State Dependence Graph research. It compiles `.wasm` binaries to Luau, LuaJIT, or Rust source files.

## Rework

This branch represents an experiment produced with no human intervention of any kind. No promises are made for the quality, safety, or stability of any of the code provided nor that produced by the compiler. Here be dragons.
